# Offline resource finder — fictional demo

Open `index.html` in a browser. No server, account, package installation or internet is needed. The catalog is synthetic and generated in `resources.js`.

**Features:** labeled text search, native category selector, clear/reset button, keyboard-accessible native controls, results count in a polite live region, descriptive result links, and informative empty state. An intentionally flawed HTML file is provided separately **only** to demonstrate candidate defects; do not publish that file as an accessible solution.

**Manual verification still required:** keyboard-only walk-through, visual focus checks, at least one screen reader/browser combination, color contrast verification, and an authorized Section 508 test method if required. No formal accessibility conformity is claimed. Refer to `documents/05_Interactive_Toolkit_Technical_Specification.pdf` and `review/accessibility_findings.csv`.
